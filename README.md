# TOURISME 243 AI — Règles de confidentialité

La page HTML bilingue est `index.html`. Elle ne dépend d’aucun script, service de suivi, police distante ou fichier PDF.

## Publier avec GitHub Pages

GitHub Pages n’est pas activé automatiquement. Pour publier vous-même la page :

1. Ouvrez **Settings** dans ce dépôt.
2. Dans **Pages** → **Build and deployment**, sélectionnez **GitHub Actions** comme source.
3. Le workflow `Deploy static content to Pages` publie le site à chaque mise à jour de `main`.
4. Attendez la réussite du workflow puis vérifiez l’adresse :
   <https://barackndenga.github.io/tourisme243-ai-privacy-policy/>

Après publication, utilisez cette URL dans le champ « URL des règles de confidentialité » de Google Play Console. Le code source Android mis à jour ouvre également cette adresse depuis l’accueil de l’application.

Chaque mise à jour de `index.html` poussée sur `main` sera ensuite publiée par GitHub Pages.
